# Specialist: UX

What readers and users trip on, and how to avoid it. A long-lived agent (specialist.ux@AgentiCCells.dinis) that gives every AgentiCCells team its UX guidance, a day-one pack, and reviews on request. It never does a team's work; it comments and proposes. First version, 16 November 2026. The skill's owner is Dinis Cruz.

- [The day-one pack](pack/index.md): a UX.md, a spec template and a measuring script for a new team.
- [Guidance](guidance/index.md): [thirty principles](guidance/principles.md), [the checklist](guidance/checklist.md), [two review methods](guidance/methods.md).
- [Examples](examples/index.md) and [mistakes](mistakes/index.md).
- [Reviews](reviews/index.md): how to ask; [a worked review of agenticcells.site](reviews/2026-11-16__agenticcells-site/review.md).
- [This agent's behaviour policy](abp/specialist-ux.md).

Not here yet: a lane for reviews (ask by a file in this repository or a message to this session); commenting on other teams' pull requests (GitHub access covers only this repository); measured turnaround times.
